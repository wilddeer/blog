## Типографика постов

Эталон английской типографики — `posts/en/2013-10-11 – Links, please/index.md`.

- **EN:** апостроф типографский `’` (`it’s`, `won’t`, `website’s`), кавычки `“ ”` (запятые и точки снаружи кавычек: `“reset your password”, and…`), тире en dash (U+2013) с пробелами ` – `, диапазоны через en dash без пробелов (`IE 7–9`), многоточие тремя точками `...`, сокращение `e.&nbsp;g.` с неразрывным пробелом, клавиши через `<kbd>`.
- **RU:** тире em dash (U+2014) с пробелами ` — `, кавычки «ёлочки».

## Деплой

- Прод — Cloudflare Pages, grumpy.blog. Production-ветка — `prod`, не `master`. Пуш в `prod` = деплой, сборка на CF занимает ~40 секунд.
- Деплоить только по прямой просьбе. Порядок: `git checkout prod && git merge --ff-only master && git push origin prod master`, потом обратно на `master`.
- Кеш по `_headers`: HTML 15 минут, картинки/svg/шрифты — год, в том числе на edge Cloudflare. Файл, изменённый под тем же именем (например, фавиконка), у читателей и на edge останется старым, пока не сменится URL (`?v=N`) или кеш не сбросят в дашборде CF.
